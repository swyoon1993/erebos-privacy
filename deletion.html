데이터 삭제 안내

기기 데이터와 문의 자료 삭제

게임은 별도 온라인 회원계정을 만들지 않습니다. 개발자 서버에 보관하는 게임 계정도 없습니다. 기기의 게임 데이터는 Android 설정 → 앱 → Erebos: Gate of Hell → 저장공간 → 데이터 삭제에서 지울 수 있습니다. 메뉴명은 기기마다 다를 수 있습니다.

이 작업으로 진행·재화 잔액이 사라질 수 있으므로 미지급·복구 문제를 조사 중이라면 먼저 고객지원에 연락해 주세요. 앱 삭제나 데이터 삭제는 결제 취소·환불 신청과 별개입니다. OS 백업이나 직접 복사한 파일은 해당 위치에서 별도로 관리해야 합니다.

문의·첨부자료 등 개발자가 보유한 정보의 삭제는 아래 이메일로 요청할 수 있습니다. 가능하면 최초 문의한 이메일에서 보내고, 요청 내용과 관련 주문번호가 있는 경우 함께 알려 주세요.

Google Play의 결제 기록과 Google 계정, Unity가 독립적으로 관리하는 정보에는 해당 제공자의 정책이 적용됩니다. 운영자를 대신해 처리하는 정보의 요청은 필요한 제공자에게 전달하여 처리합니다. Google 계정 비밀번호·카드번호는 보내지 마세요.

Data Deletion

Delete device data and support information

The Game does not create a separate online user account and the developer does not hold a game account on a server. You can erase local game data through Android Settings → Apps → Erebos: Gate of Hell → Storage → Clear data. Menu names may vary.

This may erase progress and currency balances. Contact support first if a missing-purchase or recovery issue is under investigation. Uninstalling or clearing data is separate from requesting a cancellation or refund. Manage operating-system backups or copies you made separately.
